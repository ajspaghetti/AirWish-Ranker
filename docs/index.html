AirWish Ranker

Ranks every listing in an Airbnb wishlist, anywhere in the world, and shares a shortlist to any phone.

What it does

  • Reads every listing and every review in the wishlist you have open, using your own Airbnb session.
  • Maps what is around each listing with OpenStreetMap: transit, the center, places to eat, sights, parks, the sea, lakes and rivers, and routes walking times.
  • Tags each listing (pool, rooftop, real beds for everyone, must climb stairs, damp mentioned in reviews...) and scores it in seven categories you can reweight.
  • Sort, search and filter by any tag, town, price, beds or walking time.
  • Shares up to five listings to a phone as a link, a text message or a single page file.

Install

  1. Download the repository (Code, Download ZIP) and unzip it somewhere permanent.
  2. Open chrome://extensions, turn on Developer mode, click Load unpacked and pick the extension folder.
  3. Open any Airbnb wishlist, click the AirWish Ranker icon, then Rank this wishlist.

Privacy

Everything runs in your browser. Review text is never stored, only which flags each review triggered. Shared links carry the shortlist after the # in the address, which browsers never send to this server.
