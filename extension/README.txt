AirWish Ranker 2.1 (Chrome extension, unpacked)

Install once
1. Keep this folder somewhere permanent.
2. Open chrome://extensions and turn on Developer mode (top right).
3. Click "Load unpacked" and pick this folder (or drag the folder onto the page). Pin the extension.
   Updating: replace the files, then click the reload arrow on the AirWish Ranker card.

Use
1. Log in to Airbnb and open any wishlist (airbnb.com/wishlists/...), anywhere in the world.
2. Click the extension icon, then "Rank this wishlist".
3. The results tab learns Airbnb's calls in a background tab, reads every listing and every review,
   maps what is around each listing with OpenStreetMap, routes walking times, then scores and ranks.
   About 5 to 10 minutes for 75 listings.
4. Search, sort by any column, open Filters to require or exclude tags, towns, prices, beds and walking times.
5. Click a row for the full breakdown: why it scores what it does, every tag, distances, beds, review flags.
6. Settings: presets, category weights, every factor (on/off, weight, invert), every tag (weight, Must have,
   Exclude, Avoid), flag severities, distance curves, how your group sleeps. Reset returns to the defaults.
7. "Share to phone": tick up to 5 rows (or use the top 5 in view), then copy a link, copy a text message, or download
   a single page file with photos built in. All three read well in iMessage or SMS.
8. "Copy for Google Sheets" keeps the old Data columns first, new columns after. "Download CSV" has everything.

Notes
- Everything runs in your browser with your own Airbnb session. The only other requests are to OpenStreetMap
  services (coordinates only). Review text is never stored: only which red and green flag tags each review triggered.
- SPEC.md describes every formula and default.
- If a run fails or fields come back empty, click "Copy diagnostics" and paste it to Claude.
